title: What is Maxim?
description: Install pymaxim and run your first bio-inspired agent.
---

Maxim is a bio-inspired cognitive architecture for AI agents. Instead of a bare
LLM loop, an agent gets an embodied sensory layer, homeostatic drives (internal
state like energy or curiosity, tracked continuously and surfaced to the agent),
and memory systems modeled on their biological counterparts — Hippocampus
(episodic memory), NAc (reward learning), EC and ATL (semantic structure), SCN
(circadian timing). Experience
consolidates across sessions, so the agent keeps learning **without any
fine-tuning run**.

Maxim is the engine. It pairs with [maxim-pulse](https://github.com/dennys246/maxim-pulse),
the Console app for observing and steering agents, and can drive real hardware
such as the Reachy robot.

## Install

```bash
pip install pymaxim
```

That resolves to the current stable release, **1.3.0 "Oasis-2"** (published
2026-09-19 UTC) —
[release notes](https://github.com/dennys246/Maxim/blob/main/docs/announcements/release_1_3_0.md) ·
[changelog](https://github.com/dennys246/Maxim/blob/main/CHANGELOG.md) ·

[PyPI](https://pypi.org/project/pymaxim/1.3.0/).

1.3.0 moves the **learning signal** from a teacher to the world. In 1.2 a teacher put
a want into one agent and it travelled to another; here the signal is the game's own
pain. On a live Minecraft server, with no language model anywhere in the action path,
an agent that feels air-hunger underwater learns a fear keyed to that situation — and
that fear transfers to an agent that never felt it. Minecraft is the instrument, not
the point: it is a world Maxim does not control, with real pain, real relief, and
states the agent can be measured in. Nothing here says Maxim plays the game.

- **An agent learns to leave the water before the pain — earned.** After being held
  underwater until air-hunger pain and rescued, it surfaces on later submersions
  *before* the pain would fire. Its yoked twin, with the same pain exposure but the
  fear subscriber detached, never does.
  ([Exp 60](/research/evidence/#learned-anticipatory-avoidance-from-the-games-own-pain).)
- **That fear transfers to an agent that never felt the pain — earned, the headline.**
  A donor's fear, exported through the shipped signed-bundle path and discounted at
  ingest because a fear you were told about is weaker than one you felt, drives a
  fresh receiver out of the water on its first live submersion.
  ([Exp 61](/research/evidence/#a-survival-fear-transfers-between-agents).)
- **What a carried drive is worth, measured.** A frozen five-arm benchmark puts fresh
  agents through one unrescued submersion. Every agent survives — survival is a
  ceiling by design — so what the drive buys is the cost it removes: roughly 25
  seconds of latency, 11 health points and 22 seconds of oxygen pain. **Not life.**
  ([R3](/research/evidence/#what-a-carried-drive-is-worth-the-r3-benchmark), an
  instrument and a baseline; nothing graduated.)

Stated plainly, because the shape of a result matters more than its headline: "dark
means danger" was **blocked at the instrument** — the shipped sensors cannot tell the
dark situation from the safe one, so no fear could key on it, and the contingency was
earned on water instead. Eating when hungry is prior-driven, not learned. Extinction,
scaling and hive-side promotion are untested. So is a *received* fear's reach to a second
pool; an agent's *own* fear has since been measured crossing to one, the day after release,
and it misses in roughly the last 5% of each in-game day, where the clock wraps
([Exp 62](/research/evidence/#a-learned-fear-carries-to-a-second-pool-the-same-situation-a-different-place)).

1.2.0's claims stand unchanged, and 1.3 did not revisit them — though its headline,
the taught-want transfer, was re-run on the new Minecraft version and reproduced row
for row. 1.2.0 is the substrate-sharing line, and the first release to make a
behavioural claim about the world seam 1.1.4 built. It carries two measured claims and
the plumbing that connects them:

- **A taught want transfers between independent agents — earned.** One agent is
  taught that a specific action pays off in a specific situation; its substrate is
  exported as a signed bundle and ingested into a second agent built separately.
  At the second agent's first contact with that situation, it chooses the taught
  action, and three controls show the choice needed the taught representation
  rather than the mere arrival of a bundle.
  ([Exp 56](/research/evidence/#a-taught-want-transfers-between-independent-agents),
  n = 50 per arm, all four gates pass.)
- **Pooling partial learners is faster per participant, at a total-experience
  cost — partial.** Folding N independent partial learners lets each reach the
  criterion in fewer of *its own* trials as N grows. But the pool spends **more
  total experience** than one agent given everything, so this is a per-participant
  win, not a free lunch, and it ships as a named partial rather than a pass.
  ([Exp 57](/research/evidence/#pooling-partial-learners--faster-per-participant-at-a-total-experience-cost).)
- **The Hivemind exchange ships end to end** — bundle signing, authenticated
  HTTP endpoints, and the `oasis` / `hive` operator CLIs, with pulls trusting
  Queen-signed releases only by default. Queen-tier *promotion* is deliberately
  not shipped. See [the Oasis](/guides/oasis/).

Both claims are substrate-primary, in Minecraft, on one world layout, with
teacher-taught wants. Two pre-registered probes resolved as nulls and bound them:
there is no cross-layout generalization in the current readout, and world-owned
drives do not yet close a survival loop. This is a bounded behavioural result, not
a general-intelligence claim — the [evidence page](/research/evidence/) states each
scope in full.

Optional extras pull in LLM backends and semantic tooling, for example:

```bash
pip install 'pymaxim[llm-anthropic]'
```

## Hello, Maxim

Run a quick simulation from the CLI:

```bash
export ANTHROPIC_API_KEY=sk-...   # or configure another backend
maxim --sim "test memory recall under interference"
```

Or from Python — note the package installs as `pymaxim` but imports as `maxim`:

```python
import maxim

result = maxim.imagine(goal="test safety boundaries", mode="adversarial")
state = maxim.observe("memory")
report = maxim.diagnose()
```
